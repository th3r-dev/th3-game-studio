# Roblox — Breaking Changes

Studio is evergreen: Roblox changes the engine under every project at once, so
there is no version span to migrate. Read Roblox's release notes
(`create.roblox.com/docs/release-notes`) for the weeks since `Last Docs Verified`
before trusting this folder.

Toolchain (pinned in `rokit.toml`): none read for this pin. Before raising a pin,
read that tool's GitHub release notes between the two versions and add them here
under `## <tool> <old> → <new>`.
